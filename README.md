# Hat

A random picker for when something just needs choosing. Drop in names, numbers or emoji,
then pull one out of the hat.

## What it does

- **Draw from anything.** A list you type, a number range, or a set of emoji.
- **Without replacement.** Keep drawing and nothing comes up twice until the hat is empty.
- **Saved lists.** Keep the sets you use again, and export or import them.
- **A session history**, so you can see what has already been drawn.
- **Themes**, and a share link that carries the list with it.

## Running it

```
npm install
npm run dev
```

`npm test` runs the unit tests; `npm run lint` and `npm run typecheck` are the checks CI
runs. `npm run icons` regenerates the PNG app icons after a change to the mark.
